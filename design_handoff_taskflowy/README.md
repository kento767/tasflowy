# Handoff: TaskFlowy — ツリー型TODOアプリ

## Overview
個人用の拡張TODOアプリ。タスクを複数のマインドマップ(左→右に展開する木構造)で管理し、進行中/着手可能/完了が一目で分かる。期限バッジで緊急度を色分けし、ツリーからのドラッグ&ドロップで「今日やる/明日以降やる」リストにタスクをコピーできる。

## About the Design Files
同梱の `TaskFlowy.dc.html`(+ランタイム `support.js`)は **HTMLで作られたデザインリファレンス(動くプロトタイプ)** であり、そのまま出荷するコードではない。実装先のコードベースの環境(React/Vue/Svelte など。環境が未定ならフレームワークを選定してよい — 状態管理の性質上 React + SVG を推奨)でこのデザインを再現すること。ファイル内の `<x-dc>` 内がマークアップ、`data-dc-script` 内の `class Component` がロジック(レイアウト計算・状態管理)で、アルゴリズムはそのまま移植可能。

## Fidelity
**High-fidelity。** 色・タイポグラフィ・寸法・角丸・影は最終仕様として扱い、ピクセル単位で再現する。

## 全体レイアウト
- アプリシェル: `height: 100vh; overflow: hidden` の縦flex。ヘッダー + 3カラム行(`flex:1; min-height:0`)。各カラムが個別に `overflow:auto`。
- ヘッダー: 高さ約60px、padding `18px 32px`、下線 `1px solid #eff3f4`。左に「TaskFlowy」(26px / 700)、右に凡例(進行中/着手できる/完了のスウォッチ)+日付。
- 左サイドバー「根タスク ─ 期限順」: 幅264px、背景 `#f7f9f9`、右線 `#eff3f4`、padding `24px 22px`。
- 中央キャンバス: `flex:1`、背景 `#f7f9f9`、padding `20px 32px 28px`。右上にスティッキーなツールバー(全画面ボタン + ズームコントロール)。
- 右サイドバー: 幅336px、背景 `#f7f9f9`、「今日やる」「明日以降やる」の2セクション(gap 28px)。

## Design Tokens
カラー(X風・ライト):
- 背景(カラム地): `#f7f9f9` / カード地: `#ffffff` / 完了カード地: `#eff3f4`
- テキスト主: `#0f1419` / 副: `#536471` / 淡: `#8b98a5`
- 罫線: `#eff3f4`(hairline)、カード枠: `#cfd9de`、完了カード枠: `#e1e8ed`
- アクセント青: `#1d9bf0`(進行中の枠線)、淡青地: `#e8f5fe`、青文字: `#176ca6`
- 期限バッジ: 超過 `#8f1d22`地×`#fffdf8`文字 / 3日以内・今日 `#e5484d`×`#fffdf8` / 余裕 `#f6e3bb`×`#7a5108`
- フォント: 'M PLUS Rounded 1c'(Google Fonts)一本。角丸: カード16px / ボタン類12px / ピル999px
- カード影: `0 1px 3px rgba(15,20,25,.14)`(完了カードは影なし)

## Screens / Components

### 1. マインドマップノード(タイル)
- 寸法: 幅250px × 高さ70px 固定。padding `10px 16px`(進行中は `9px 16px`)。
- 3状態:
  - **未着手**: 白地、枠 `1px #cfd9de`、影あり
  - **進行中**: 白地、枠 `2px #1d9bf0`、影あり
  - **完了**: 地 `#eff3f4`、枠 `1px #e1e8ed`、影なし、全文字グレー
- 1行目: タスク名。ルート18px/子17px、太字700(完了は500)、色 `#0f1419`(完了は `#8b98a5` + 打ち消し線)。1行省略(ellipsis)。完了はタイトル後に「 ✓」。
- 2行目(チップ行、margin-top 6px、gap 6px): 「進行中」チップ(淡青ピル) → 「次にやる」チップ(白地+グレー枠のアウトラインピル。着手可能な葉に付く) → 期限バッジ。ピルは共通仕様: 10.5px/700/padding `1px 7px`/radius 999px。
- 期限バッジの文言: 超過=`8/2 ・ 1日超過`、今日=`今日 ・ 8/3`、3日以内=`8/7 ・ あと4日`、それ以外=`8/14 ・ あと11日`。残り日数は毎日再計算。
- ノード右端のボタン(円形、右端に-13pxはみ出す):
  - 子を持つノード: 上に折りたたみトグル(26px円、地 `#273340`、白文字、−/+)
  - 全ノード: 「＋」子タスク追加(26px円、白地、青枠 `1px #1d9bf0`、hoverで淡青地)。子持ちは折りたたみの下(top36px)、葉はtop19px。
- ドラッグ: 完了以外は `draggable`、`cursor: grab`。

### 2. ツリーレイアウト(中央キャンバス)
- 複数ツリーを縦に並べ、各ツリーの間に hairline 区切り(padding/margin 24px)。
- 各ツリー見出し: kicker(12px、letter-spacing 2px、グレー)「タスク名 ─ 期限 8/31」+「＋ タスク追加」リンク(ルートに子を追加)。
- レイアウトアルゴリズム(移植必須):
  - 列: `x = 20 + depth * 306`、ノード幅250。行送り: 葉ごとに `y += 92`。
  - 葉(または折りたたみ中)ノード: 現在のカーソル位置に配置しカーソルを進める。親ノード: `y = (最初の子のy + 最後の子のy) / 2`。
  - コネクタ: 親の右端中央 `(x+250, y+35)` から子の左端中央への3次ベジェ `M sx,sy C sx+36,sy ex-36,ey ex,ey`。SVGで描画、stroke `#8b98a5`、太さ1.5。
  - キャンバス幅: `max(1150, 最深列x + 250 + 20)`。
- ズーム: 40%〜200%。ボタン(−/%表示/+、%クリックで100%)と、**トラックパッドのピンチ**(`wheel` イベントで `ctrlKey===true` のとき `preventDefault` して `zoom *= exp(-deltaY * 0.012)`、リスナーは `passive:false`)。適用はキャンバスラッパーに CSS `zoom`。
- 全画面: ボタンでキャンバスだけを `position:fixed; inset:0; z-index:50` に。Escで解除。

### 3. 左サイドバー(根タスク一覧)
- ルートタスクを期限昇順でソートして表示。
- カード: 高さ68px固定、白地、枠 `1px #cfd9de`、radius 16px、影、padding `0 14px`。1行目タスク名(15px/700/黒/省略)、2行目に進行中チップ+期限バッジ。
- クリックで中央キャンバスを該当ツリーへスムーズスクロール(`scrollIntoView` は使わず、コンテナの `scrollTo`)。
- 下に「＋ 根タスクを追加」テキストボタン。

### 4. 右サイドバー(今日やる / 明日以降やる)
- 各セクション: kicker見出し(今日やる=グレー12px+右に日付)、その下に **破線枠のドロップゾーン**(`1px dashed #cfd9de`、radius 12px、min-height 96px)。
- ドロップゾーン内のアイテムカード: 根タスクカードと同一デザイン(白地/枠/影/radius16px)。左に15px円形チェック(枠のみ)、タスク名15px/700/黒、下段にパス(11.5px グレー、例「引っ越し準備 / 荷造り」)+期限バッジ、右上に「×」削除。
- ゾーン最下部に常時ヒント「ツリーからここへドラッグでコピー」(12px、中央、淡グレー)。
- D&D: ツリーのノードをドラッグ→ゾーンにドロップで**コピー**(ツリーからは消えない)。同一タスク(タイトル+パス)の重複追加は無視。`dragover` で `preventDefault` + `dropEffect='copy'`。

### 5. 子タスク追加ダイアログ
- ノードの「＋」または見出しの「＋ タスク追加」で開く。背景 `rgba(0,0,0,.55)` 相当のオーバーレイ、中央に幅420pxの白カード(radius 12px、影lg、padding `26px 28px`)。
- 内容: タイトル「子タスクを追加」+ 副文「「◯◯」の下に追加します」、フィールド2つ(タスク名 *必須* / 期限 *任意、M/D形式*)、右下に「キャンセル」「追加」。
- 追加すると親の子として未着手ノードが生え、ツリーが自動リレイアウト。親が折りたたみ中なら展開する。オーバーレイクリックで閉じる(カード内クリックは伝播停止)。

## State Management
- `trees`: ツリーのネスト構造 `{id, title, due?, status: 'done'|'active'|'todo', next?, done?(完了日), children?}`
- `collapsed`: {nodeId: bool} / `zoom`: number / `full`: bool
- `today` / `later`: `{title, path, due}[]`(ドロップでコピーされたもの)
- `addFor`: 追加対象の親ノードid(null=ダイアログ閉)+ フォーム入力2つ
- 進行中(`active`)・完了(`done`)はデータ上のステータス。「次にやる」は `next` フラグ。
- プロトタイプでは永続化なし。実装では localStorage かバックエンドに `trees`/`today`/`later` を保存すること。
- 日付: プロトタイプは「今日=2026-08-03」固定。実装では実際の今日を使う。

## サンプルデータ
プロトタイプ内 `seedTrees` 参照(引っ越し準備 / ポートフォリオ制作 / 歯医者の予約 の3ツリー、深さ最大4)。

## Assets
外部アセットなし。フォントは Google Fonts の 'M PLUS Rounded 1c'(400/500/700)。アイコンは全て文字グリフ(−, +, ×, ✓)と小さなインラインSVG(全画面アイコン)。

## Files
- `TaskFlowy.dc.html` — デザイン本体(マークアップ+ロジック+全トークン)。レイアウト計算・ピンチズーム・D&Dのロジックはここから移植する。
- `support.js` — プロトタイプ専用ランタイム。**実装には不要**(参照もしなくてよい)。
